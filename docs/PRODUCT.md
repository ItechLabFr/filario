# Produit Filario

## Proposition

Filario centralise la vie complète d'une bobine de filament, de l'achat à sa consommation.

## Dashboard

- stock total ;
- poids restant ;
- valeur du stock ;
- bobines faibles ;
- consommation ;
- séchage à prévoir ;
- état des imprimantes.

## Inventaire

Vues :

- grille ;
- liste ;
- tableau ;
- emplacement.

Filtres :

- marque ;
- matière ;
- couleur ;
- poids ;
- emplacement ;
- état ;
- imprimante.

## Bobine

Une bobine peut contenir :

- fabricant ;
- gamme ;
- matériau ;
- couleur ;
- diamètre ;
- poids initial ;
- poids restant ;
- tare ;
- densité ;
- températures ;
- prix ;
- fournisseur ;
- lot ;
- dates ;
- emplacement ;
- photos ;
- notes.

## Historique

Toute action importante devient un événement :

- création ;
- pesée ;
- consommation ;
- chargement ;
- déplacement ;
- séchage ;
- correction ;
- suppression/restauration.

## QR

Chaque bobine dispose d'un QR.

Actions rapides :

- utiliser ;
- peser ;
- déplacer ;
- sécher ;
- charger ;
- afficher l'historique.

Le QR ne doit pas embarquer toutes les données de la bobine.

## Imprimantes

Gestion :

- imprimante ;
- slots ;
- bobines chargées ;
- intégrations ;
- consommations.

## Projets et impressions

Une impression peut associer :

- fichier ;
- imprimante ;
- durée ;
- filament prévu ;
- filament réel ;
- coût ;
- résultat ;
- photos.

## Catalogue

Filario conserve une copie locale des données de catalogues externes.

Les recommandations externes restent distinctes des profils personnels.

```text
Recommandation fabricant
Buse : 190–230 °C

Profil personnel
Bambu X1C / 0.4 mm : 220 °C
```

## Design

Direction :

- premium ;
- industrielle mais chaleureuse ;
- peu décorative ;
- rapide ;
- accessible ;
- adaptée clair/sombre ;
- couleur du filament utilisée comme information visuelle.

À éviter :

- glassmorphism excessif ;
- gradients « IA » ;
- animations inutiles ;
- assistant conversationnel au centre du produit.
